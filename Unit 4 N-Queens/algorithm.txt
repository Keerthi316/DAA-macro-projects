============================================================
              N-QUEENS - ALGORITHM & PSEUDOCODE
                    State Space Tree (N = 4)
============================================================

ALGORITHM
---------

1. Start with an empty chessboard.

2. Place queens one row at a time.

3. For the current row, try placing a queen in every column.

4. Check whether the position is SAFE:
      - No queen is in the same column.
      - No queen is on the same diagonal.

5. If the position is safe:
      - Place the queen.
      - Recursively place a queen in the next row.

6. If the position is not safe:
      - Mark the branch as INVALID.
      - Try the next column.

7. If all N queens are placed:
      - A solution is found.

8. After exploring a position:
      - Remove the queen.
      - Backtrack and try the next possible position.


PSEUDOCODE
----------

NQUEENS(row)

    IF row == N THEN
        PRINT "Solution Found"
        RETURN

    FOR col = 0 TO N - 1 DO

        IF SAFE(row, col) THEN

            PLACE queen at (row, col)

            NQUEENS(row + 1)

            REMOVE queen from (row, col)
            // Backtrack

        ELSE

            MARK branch as INVALID

        END IF

    END FOR


SAFE(row, col)

    FOR each previously placed queen (r, c) DO

        IF c == col THEN
            RETURN FALSE
            // Same column

        IF ABS(r - row) == ABS(c - col) THEN
            RETURN FALSE
            // Same diagonal

    END FOR

    RETURN TRUE


============================================================
                         RESULT
============================================================

For N = 4, the two valid solutions are:

    1. [2, 4, 1, 3]
    2. [3, 1, 4, 2]

Technique Used: BACKTRACKING
============================================================
