Algorithm: 0/1 Knapsack using Branch and Bound
Input: n items with weights and profits, knapsack capacity W
Output: Maximum possible profit
1. Sort all items in decreasing order of profit/weight ratio.
2. Create the root node with:
   - level = -1
   - weight = 0
   - profit = 0
3. Calculate the upper bound of the root node.
4. Insert the root node into a priority queue.
5. Set maxProfit = 0.
6. While the priority queue is not empty:
   - Remove the node having the highest bound.
   - If bound ≤ maxProfit, prune the node.
   - Otherwise, generate two child nodes:
     - Include the next item.
     - Exclude the next item.
7. For the include node:
   - Add the item's weight and profit.
   - If its weight does not exceed W, calculate its bound.
   - Update maxProfit if its profit is greater.
   - Insert it into the queue if its bound is greater than maxProfit.
8. For the exclude node:
   - Keep the same weight and profit.
   - Calculate its bound.
   - Insert it into the queue if its bound is greater than maxProfit.
9. Repeat until the priority queue becomes empty.
10. Return maxProfit.

Pseudocode:
BranchAndBoundKnapsack(items, capacity):

    Sort items according to profit/weight ratio

    Create root node
    root.level = -1
    root.profit = 0
    root.weight = 0
    root.bound = CalculateBound(root)

    Insert root into priority queue

    maxProfit = 0

    while priority queue is not empty:

        node = remove node with highest bound

        if node.bound <= maxProfit:
            continue

        next = node.level + 1

        // Include next item
        if node.weight + weight[next] <= capacity:

            create includeNode

            includeNode.weight =
                node.weight + weight[next]

            includeNode.profit =
                node.profit + profit[next]

            calculate bound(includeNode)

            if includeNode.profit > maxProfit:
                maxProfit = includeNode.profit

            if includeNode.bound > maxProfit:
                insert includeNode

        // Exclude next item
        create excludeNode

        excludeNode.weight = node.weight
        excludeNode.profit = node.profit

        calculate bound(excludeNode)

        if excludeNode.bound > maxProfit:
            insert excludeNode

    return maxProfit
