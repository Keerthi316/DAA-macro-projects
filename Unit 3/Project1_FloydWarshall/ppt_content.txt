SLIDE 2: Problem Statement
------------------------------------------------------------
Title: Problem Statement

• Given a weighted directed graph with n vertices and edges,
  find the SHORTEST PATH between EVERY PAIR of vertices.

• The graph may contain:
    - Positive edge weights
    - Negative edge weights (but no negative cycles)

• Output: An n × n distance matrix where
    dist[i][j] = shortest distance from vertex i to vertex j

• Example Use Cases:
    - Network routing
    - GPS navigation
    - Traffic flow analysis
    - Social network analysis

------------------------------------------------------------
SLIDE 3: What is Floyd-Warshall?
------------------------------------------------------------
Title: Floyd-Warshall Algorithm

• A classic Dynamic Programming algorithm

• Proposed by Robert Floyd (1962) and Stephen Warshall (1962)

• Solves the All-Pairs Shortest Path (APSP) problem

• Key Idea:
    Improve path estimate between every pair (i, j)
    by checking if going through an intermediate vertex k
    gives a shorter path.

• Recurrence Relation:
    dist[i][j] = min( dist[i][j],  dist[i][k] + dist[k][j] )

  For every intermediate vertex k = 0, 1, 2, ..., n−1

------------------------------------------------------------
SLIDE 4: Algorithm Steps
------------------------------------------------------------
Title: Algorithm — Step by Step

Step 1: Initialize the distance matrix
        dist[i][j] = weight of direct edge (i → j)
        dist[i][j] = INF  if no direct edge
        dist[i][i] = 0    (distance to itself)

Step 2: For each intermediate vertex k (0 to n−1):
           For each source vertex i (0 to n−1):
              For each destination vertex j (0 to n−1):
                 if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

Step 3: Final matrix contains all-pairs shortest distances.

Step 4: If dist[i][i] < 0 for any i → Negative cycle detected!

SLIDE 8: Complexity Analysis
------------------------------------------------------------
Title: Complexity Analysis

Time Complexity:
    Three nested loops (k, i, j) each running n times
    → O(n³)

Space Complexity:
    Single n × n distance matrix
    → O(n²)

Comparison with other APSP algorithms:
┌────────────────────┬────────────┬────────────┐
│ Algorithm          │ Time       │ Notes      │
├────────────────────┼────────────┼────────────┤
│ Floyd-Warshall     │ O(n³)      │ All pairs  │
│ Dijkstra (n times) │ O(n² logn) │ No neg wt  │
│ Bellman-Ford (×n)  │ O(n² · E)  │ Neg weights│
└────────────────────┴────────────┴────────────┘

Floyd-Warshall is preferred when:
  - Graph is dense
  - Negative weights are present
  - Simple implementation is needed

SLIDE 9: Advantages & Limitations
------------------------------------------------------------
Title: Advantages & Limitations

Advantages:
  ✔ Simple and easy to implement
  ✔ Handles negative edge weights
  ✔ Finds ALL pairs in one run
  ✔ Detects negative cycles

Limitations:
  ✘ O(n³) — slow for very large graphs
  ✘ Does not work with negative cycles
  ✘ Not suitable for sparse graphs
     (Dijkstra repeated is more efficient)

SLIDE 11: Code Snippet
------------------------------------------------------------
Title: Core Algorithm — Python Code

def floyd_warshall(graph):
    n = len(graph)
    dist = [row[:] for row in graph]  # copy matrix

    for k in range(n):                # intermediate vertex
        for i in range(n):            # source
            for j in range(n):        # destination
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    return dist

Key Points:
  • dist[i][k] != INF and dist[k][j] != INF checked before update
  • Matrix is updated IN-PLACE per iteration of k
  • Final matrix = all-pairs shortest path solution
