# DAA Sorting Lab Pro

## Unit I – Algorithm Analysis
An interactive sorting algorithm visualization website.

### Algorithms
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

### Main Features
- Generate random arrays
- Enter your own elements
- Select array size
- Control animation speed
- Animated comparison and swap visualization
- Live comparison count
- Live swap/move count
- Progress percentage
- Runtime display
- Complexity display
- Pivot visualization for Quick Sort
- Sorted-position visualization
- Algorithm explanation
- Best/Average/Worst complexity table
- Responsive modern dark interface
- Works directly in Chrome/Edge
- No backend required

## Run
Extract the folder and double-click:
`Sorting_Algorithm_Visualizer.html`
