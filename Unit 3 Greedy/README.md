# DAA Optimal Merge Pattern Lab

## Unit III – Greedy Method
An interactive visualization of the Optimal Merge Pattern with a weighted binary merge tree.

### Problem
Draw a binary tree showing optimal merge pattern for files of sizes 10, 20, 30, 40.

### Result
- Merge 10 + 20 = 30 (cost 30)
- Merge 30 + 30 = 60 (cost 60)
- Merge 40 + 60 = 100 (cost 100)
- **Minimum total cost = 190**

### Main Features
- Weighted merge tree drawn step by step
- Enter your own file sizes (2–10 values)
- Next Merge, Auto Play, Reset and speed control
- Live sorted working list
- Merge step log
- Total cost vs largest-first cost
- Algorithm explanation and complexity
- Responsive dark glassmorphism interface
- Works directly in Chrome/Edge, no backend

Extract the folder and double-click:
